SNI block PoC

The (first-party) tracker script stores an ID and reports to https://<id>./collect. Block that request and check whether the ID still appears in a TLS ClientHello (server log or Wireshark).

On load: ?mode=fetch (default), beacon, preconnect, dnsprefetch, none, or combined like ?mode=preconnect,fetch. Add &id=… for a fixed ID, &tp=1 to load the script from the tracker domain.
